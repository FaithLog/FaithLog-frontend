# #303 입력 오류·알림 사유·작성 보존 / #304 투표 자동 갱신

## 동작

- 검증 오류 응답의 선택적 `data.fieldErrors: [{field, code}]`를 알려진 필드·제약 코드에 한해 한국어 안내로 변환한다. 입력값이나 서버 임의 메시지를 출력하지 않는다. 기존 서버의 `field: message` 응답도 알려진 필드에 한해 안전한 안내로 변환한다.
- 계좌 등록의 로컬 검증과 서버 검증, 로그인, 회원가입 상세, 캠퍼스 생성의 서버 필드 오류를 입력칸에 표시한다. 그 외 화면은 공통 오류 요약으로 확인할 수 있다.
- 관리자 알림 제외 명단과 발송 기록이 동일한 한국어 사유를 사용한다. 기기 수신 정보 없음이 실제 OS 알림 OFF를 의미한다고 단정하지 않는다. 알 수 없는 사유는 원문을 노출하지 않는다.
- 공통 오류 화면은 재시도로 해결되지 않는 오류에 재조회 버튼을 표시하지 않는다. 경건 제출 실패는 작성 내용을 유지한 채 계속 입력할 수 있다. 이미 제출된 주차는 기존 최신 기록 조회 흐름을 유지한다.
- 투표 화면은 포그라운드에서 5초 간격으로 목록 또는 상세·결과를 조용히 갱신한다. 댓글은 댓글 탭에서 갱신한다. 앱 복귀 시 즉시 갱신하고, 백그라운드·언마운트 시 중지한다. WebSocket 방식이 아니라 기존 조회 API를 사용하는 근실시간 갱신이다.
- 자동 조회가 겹치지 않으며, 화면·캠퍼스·인증 세션 전환 후 늦게 도착한 응답과 저장 작업 이전 조회 응답을 반영하지 않는다. 작성 중인 선택·댓글·추가 항목 폼을 초기화하지 않는다.
- 일시적 갱신 실패 시 마지막 현황과 실패 안내를 표시한다. 권한 거부·삭제는 기존 현황을 계속 표시하지 않는다. 익명으로 바뀐 투표에서 이전 공개 응답자 명단을 재사용하지 않는다.

## 검증

- 타입 검사 통과, 린트 오류 없음(기존 screenMode 미사용 경고 1건).
- 외부 네트워크 연결을 차단한 전체 테스트: 237개 파일 / 1,948개 테스트 통과.
- 검증 응답 정규화·레거시 호환·민감정보 비노출·입력칸 오류·경건 입력 보존·알림 사유를 검증했다.
- 실제 PollScreen을 렌더링하여 5초 갱신 후 집계 변경과 미저장 선택 유지, 백그라운드 중지·복귀 즉시 갱신·언마운트 중지, 중복 조회 방지, 실패 시 마지막 집계 유지와 자동 복구를 검증했다.
- 이전 선택지 추가 소스 경계 테스트는 저장 시작 함수가 자동 갱신의 이전 응답을 무효화하는 변경에 맞춰 동기화했다.

## 전달

관련 백엔드: FaithLog-backend #266. 신형 서버는 여러 필드 오류를 제공하며, 구형 서버에서는 기존 단일 필드 정보를 활용한다. API 상태·업무 검증 규칙·DB·권한은 바꾸지 않았다. 실제 모바일 기기에서 화면 길이와 앱 전환 동작의 시각 확인은 미실행이다. 이번 변경은 검토용 브랜치이며 병합·스토어 배포는 수행하지 않았다.

다음 앱 배포가 이미 제출된 1.2.8과 겹치지 않도록 앱·패키지·릴리스 검증 버전을 1.2.9로 준비한다. 플랫폼별 빌드 번호는 기존 EAS 원격 자동 증가 설정을 유지한다.

## #306 커피·밥 담당자 정산

- 기존 두 서버 API 모두 status 조건을 지원한다. 커피 화면의 ALL 조회 후 현재 페이지 로컬 필터와 5명 제한을 제거하고, 밥 정산 API 래퍼에도 status 쿼리를 연결했다. 관리자 공통 정산은 이미 서버 조건을 전달하므로 유지했다.
- 기본 미납 탭에서 시작하며 미납·납부·전체 조건을 서버 집계와 페이지 조회에 적용한다. 상태 변경과 이전 기록 전환은 첫 페이지부터 조회하고, 새로고침·페이지 이동은 선택 상태를 유지한다. 총 인원과 합계는 서버 응답을 따른다.
- 빈 미납 결과에서도 납부·전체 탭을 사용할 수 있다. 오래된 조회 응답은 현재 상태를 덮어쓰지 않는다. 전체 미납 알림은 현재 표시 탭과 별개의 기존 전체 담당 범위로 요청한다.
- 커피 요청의 서버에서 무시되는 paymentAccountId 쿼리를 제거했다. 기존 내 활성 계좌 전체 조회 범위는 유지한다. 모의 밥 API도 상태별 필터를 집계·페이지 분할 전에 적용한다.
- 회귀 테스트는 변경 전 실패를 확인한 후, 상태별 서버 요청·빈 결과 전환·페이지/새로고침/이전 기록 조건 유지·커피 10명 표시·응답 역전을 검증했다. 타입 검사, 린트(기존 경고 1건), 외부 통신 차단 전체 237개 파일/1,948개 테스트 통과.
