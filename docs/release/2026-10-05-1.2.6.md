- 복구된 소스의 전체 ci: 타입 검사/린트 통과, 233개 파일/1,890개 테스트 통과.

- 업로드 전 archive 검증에서 토스 송금, 납부·경건 화면, 관리자 수정, 새 명단 컴포넌트, Kakao native 모듈이 워크스페이스와 동일함을 확인했다.
- 기존 iOS/Android 로컬 native 폴더를 업로드에서 제외하며 EAS에서 config plugin을 적용해 재생성한다.
- QA 산출물·복구 백업·로컬 환경 변수 파일을 업로드에서 제외했다.
- EAS production의 기존 원격 서명·제출 자격 증명을 사용했다. Firebase 설정은 secret 변수, Kakao 설정은 기존 production 변수로 공급한다.
- 소스 식별 기록: artifacts/release-1.2.6/manifest.json. Git HEAD 70e61e4에 미커밋 로컬 변경을 포함하므로 Git SHA만으로 빌드 소스를 재현할 수 없다. 원본 로컬 변경은 백업 stash에 유지했다.

## 범위

EAS Submit 완료는 Apple/Google의 스토어 처리, 심사 승인, 일반 사용자 공개 완료를 뜻하지 않는다. Android 제출은 내부 테스트 트랙이다.

실제 토스 앱이 설치된 기기의 송금 화면과 Android 설치본 QA는 별도 검증이 필요하다. 최신 native 빌드의 설치·푸시·공유·송금 화면 확인을 권장한다.

## Android 재시도

첫 Android 빌드 71(7526a82d-b5bf-49eb-9cd1-7c019e36b861)은 EAS SERVER_ERROR: Failed to upload application archive로 실패했고 연결 제출은 CANCELED였다. worker 로그의 세부 오류는 Turtle build is not in progress, it cannot save artifacts였다. 같은 소스로 빌드 72를 재요청했다.

## 주간 목홀타 확인

1.2.6 소스에 홈 카드와 입력·수정·완료 표시가 포함돼 있다. 관련 프론트 테스트 8개 파일/23개 통과. 백엔드 origin/main의 ShepherdService.getMyHome은 Asia/Seoul 일요일에 담당 목장이 있는 경우에만 visible=true를 반환한다. 현재 운영 서버에서 일요일 시점을 재현한 검증은 수행하지 않았다.
