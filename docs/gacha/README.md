# 동물 친구 뽑기: 승인된 애니메이션

2026-11-10에 확정한 뽑기 연출의 실행 가능한 원본이다.
`draw-animation.html`을 브라우저에서 열면 의존성 설치와 서버 없이 확인할 수 있다.

## 포함된 동작

- 1개 뽑기, 10개 뽑기. 10개는 알 10개를 보여준 다음 순서대로 공개한다.
- 등장 전 알의 작은 들썩임 → 입자가 알로 모임 → 빛나는 균열 → 껍질 분리와 파편 → 캐릭터 상승 → 착지 반동 → 이름 표시.
- 일반: 앱의 민트색. 희귀: 보라색 입자·후광. 유니크: 금빛 입자·방사광·확산 파동.
- 일반은 빠르게, 희귀·유니크는 길게 공개한다. 진행 점과 공개 순번을 표시한다.
- 건너뛰기를 눌러도 10개 결과는 모두 유지한다. 재생 중 중복 실행을 막는다.
- `prefers-reduced-motion`에서는 이동·파편·긴 애니메이션을 생략한다.

## 디자인

현재 `src/theme.ts` 기준: 배경 `#F7F8FA`, 액션 `#2368D3`, 민트 `#92C7CF`, 본문 `#191F28`, 보조 본문 `#4E5968`.
희귀 등급 색은 연출 안에서만 사용한다. 버튼 높이 48, 모서리 14, 화면 좌우 여백 24를 따른다.

## 앱 연결 시 계약

이 파일은 승인된 연출을 보존하는 HTML Canvas 미리보기이며 React Native 화면에는 아직 연결하지 않았다.
앱에는 React Native Animated와 기존 react-native-svg 등 프로젝트에서 쓰는 수단으로 이 타이밍과 움직임을 옮긴다. HTML 파일 자체는 네이티브 컴포넌트가 아니다.

- 앱의 서버가 확정한 결과 목록을 전달받아 순서대로 재생해야 한다. 애니메이션에서 확률·재화 차감·소유권을 결정하지 않는다.
- 데모의 등급 선택은 연출 확인 전용이다. 10개 시연은 선택 등급을 여덟 번째 결과에 넣는다. 실제 보장 확률을 뜻하지 않는다.
- 현재 `animal()`은 임시 캐릭터다. 승인된 동물·의상 에셋과 모션으로 교체해야 한다. 이 데모의 픽셀 그림을 최종 에셋으로 사용하지 않는다.
- `friendPose()`의 위치·크기·착지 반동에 실제 캐릭터를 연결한다. 알·입자·껍질 연출은 캐릭터 디자인과 독립적이다.
- 건너뛰기·백그라운드 복귀·모션 줄이기에서도 이미 확정된 전체 결과를 유지한다. 종료·언마운트 시 타이머와 애니메이션을 정리한다.
- 앱에서 미리보기 등급 선택과 데모 안내를 제거하고, 실제 결과와 재화 UI를 연결한다.

## 타이밍

| 단계 | 1개 뽑기 | 10개 뽑기 |
| --- | ---: | ---: |
| 알 10개 집합 | 없음 | 최초 1,000ms |
| 기대감 / 들썩임 | 800ms | 친구당 360ms |
| 빛 모으기 / 균열 | 일반 500ms, 희귀·유니크 1,250ms | 동일 |
| 열림 / 상승 / 착지 / 이름 | 일반 950ms, 희귀 1,800ms, 유니크 2,300ms | 동일 |

## 확인 기록

- JavaScript 구문 검사 통과.
- 실제 Canvas 렌더러와 DOM 대체 환경에서 일반·희귀·유니크 각 1개 결과, 10개 결과, 유니크 강조, 건너뛰기 후 10개 결과 유지 확인.
- 유니크 연출 프레임을 이미지로 렌더링하여 확인.
- 이 환경의 브라우저 실행 제한으로 실제 브라우저 전체 동작 및 iOS/Android 앱 검증은 수행하지 못했다.
- 앱 런타임·의존성·버전 변경 없음. agent.md가 참조하는 .harness 문서들은 현재 develop 체크아웃에 존재하지 않는다.
