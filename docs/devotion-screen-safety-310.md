# 경건생활 저장 및 벌금 표시 개선 (#310)

- 저장/납부 처리 중 주차 이동을 막고, 저장 응답은 요청 당시 주차와 현재 화면이 같을 때만 반영한다.
- 주차 이동 전 미저장 변경이 있으면 저장 후 이동, 변경 취소 후 이동, 계속 작성을 제공한다. 저장 실패 시 입력과 현재 주차를 유지한다.
- 제출 후 벌금은 현재 규칙으로 재계산하지 않고 실제 청구 금액을 사용한다. 청구가 없으면 청구 없음, 조회 실패면 확인 실패로 구분한다.
- 해당 주 청구를 찾거나 마지막 페이지에 도달할 때까지 납부 목록을 조회한다.
- 경건 기준은 규칙의 requiredCount를 사용하고 지각 벌금은 별도로 안내한다.
- 지각 예상액은 기본금과 분당 금액을 합산한 후 최대 5,000원으로 제한한다. 다른 경건 벌금에는 이 상한을 적용하지 않는다.

프론트만 변경했다. 서버 청구 금액/정책과 기존 청구는 바꾸지 않는다. 서버 계산에 5,000원 상한이 없다면 예상액과 실제 청구액에 차이가 발생할 수 있으며, 프론트는 실제 청구 금액을 숨기거나 변경하지 않는다.

검증: 회귀 테스트 RED 3건 확인 후 수정. 타입 검사 및 lint 통과. 전체 239개 테스트 파일, 1,984개 테스트 통과. 실기기 시각 검증은 실행하지 않았다.
