# 전체 디자인 모션

기본형 13종과 추가 의상 117종, 총 130종에서 `idle` / `walk` / `happy` / `held` / `land`를 사용할 수 있습니다.

| 모션 | 프레임 | 슬롯 | 반복 |
| --- | ---: | --- | --- |
| 대기·호흡 idle | 4 | 0–3 | 반복 |
| 걷기 walk | 4 | 4–7 | 반복 |
| 터치·기쁨 happy | 4 | 8–11 | 1회 후 회복 자세 유지 |
| 들려 있기 held | 2 | 12–13 | 반복 |
| 내려놓기 land | 2 | 14–15 | 1회 후 회복 자세 유지 |

- 의상별 **768×768 투명 PNG 1장**, 192×192 셀 4열×4행, 좌상단부터 행 우선 순서입니다. 기준점은 셀 내부 (96,176)입니다.
- 새 아틀라스 117장(총 약 13.79 MiB)에 **1,872개 재생 프레임**이 들어 있습니다. 기존 기본형 208장과 합쳐 총 **2,080프레임**입니다.
- 각 의상의 생성형 핵심 포즈 6개(중립·좌우 걸음·기쁨·들림·착지)에 호흡·오르내림·회복 중간 프레임을 조합했습니다. 16장을 모두 별도로 그린 애니메이션은 아닙니다. 학자 계열의 들림 포즈는 의상 일관성을 위해 중립 포즈에서 파생했습니다.
- 물리적인 이동·터치·드래그는 앱이 처리하고, 그 상태에 맞는 모션과 경과 시간을 렌더러에 전달합니다. 고래·새는 걷기 슬롯을 이동 흔들림/날갯짓으로 해석합니다.
- 생성형 프레임 간 작은 소품·색감·외형 차이가 있습니다. 실제 기기에서 64~96dp 크기의 가독성과 프레임 전환을 확인하세요.

## React Native 사용

```tsx
import { BibleFriendDesignSprite } from './src/characters/BibleFriendDesignSprite';

<BibleFriendDesignSprite
  designId="hope-rabbit:unique"
  motion="walk"
  elapsedMs={elapsedMs}
  size={96}
/>
```

루트 컴포넌트 기준 import 예시입니다. `elapsedMs`는 현재 모션이 시작된 뒤의 시간이며 모션 변경 때 0으로 초기화합니다. 화면 이탈·백그라운드에서는 공유 시계를 멈추고, 동작 줄이기를 원하면 0을 전달합니다. 컴포넌트 내부 타이머가 없어 여러 캐릭터가 하나의 시계를 사용할 수 있습니다.

기본형은 기존 개별 프레임을, 의상은 동일한 PNG 아틀라스의 위치를 바꿔 표시합니다. Metro가 정적 require로 모두 번들링하며 네트워크를 요청하지 않습니다. 화면상의 이동, 터치 이벤트, 포인트, 뽑기, 소유권 저장은 연결하지 않았습니다.

`manifest.json`은 각 아틀라스 파일·크기·바이트·원본 시트 이름·슬롯/타이밍을 기록합니다. TypeScript 타임라인과 파일 목록을 테스트로 대조합니다.

## 개발 확인

저장소 루트에서 `python3 -m http.server 8080` 실행 후:

`http://localhost:8080/assets/characters/bible-friends/design-motions/preview.html`

전체 130종을 모션별로 재생하고 캐릭터·의상을 필터링할 수 있습니다. 앱 화면이 아닌 개발용 뷰어입니다.
