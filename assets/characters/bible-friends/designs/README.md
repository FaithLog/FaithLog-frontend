# 수집형 디자인 · 13종 × 10개 = 130종

각 기본 캐릭터에 기존 기본형 1개와 새로운 디자인 9개를 제공합니다. 유니크는 13종 모두 전용 이름·의상·소품을 가집니다.
새 투명 PNG는 총 117장이고, 기본형 13장은 기존 파일을 재사용합니다.

## 기본 확률 초안

아래 확률은 **전체 130종 풀** 기준입니다. 같은 동물의 10개 디자인만 따로 뽑는 경우에는 해당 동물로 풀을 제한한 뒤 다시 정규화해야 합니다.

| 디자인 | 등급 | 가중치 | 이 디자인 계열 전체 확률 | 특정 동물 1개의 확률 |
| --- | --- | ---: | ---: | ---: |
| 기본 | 일반 | 240 | 24% | 1.846154% |
| 햇살 소풍 | 일반 | 160 | 16% | 1.230769% |
| 작은 학자 | 일반 | 140 | 14% | 1.076923% |
| 초록 정원사 | 고급 | 120 | 12% | 0.923077% |
| 바다 선원 | 고급 | 100 | 10% | 0.769231% |
| 숲 탐험가 | 고급 | 80 | 8% | 0.615385% |
| 등불 축제 | 희귀 | 65 | 6.5% | 0.5% |
| 별빛 잠옷 | 희귀 | 45 | 4.5% | 0.346154% |
| 로열 가든 | 에픽 | 40 | 4% | 0.307692% |
| 동물별 전용 유니크 | 유니크 | 10 | 1% | 0.076923% |

등급 합계: **일반 54% / 고급 30% / 희귀 11% / 에픽 4% / 유니크 1%**.
동물별 합계는 1/13로 동일합니다. 유니크 1%는 13종을 합친 확률이며, 특정 유니크 한 개는 1/1300입니다.
설정은 확정 운영 정책이 아닌 조정 가능한 초안입니다. 가중치를 바꾸면 실제 분모와 표시 확률도 같이 다시 계산합니다.

## 앱에서 사용

```tsx
import { Image } from 'react-native';
import { BIBLE_FRIEND_DESIGN_IMAGES } from './src/characters/bibleFriendDesignAssets';
import {
  createBibleFriendDrawPool,
  getBibleFriendDesignProbability,
  pickBibleFriendDesign,
} from './src/characters/bibleFriendDesignDraw';

// 로컬 체험용 선택 예시. 포인트 차감이나 소유권 저장은 하지 않습니다.
const pool = createBibleFriendDrawPool();
const design = pickBibleFriendDesign(pool, Math.random());
const probability = getBibleFriendDesignProbability(pool, design.id);

<Image
  source={BIBLE_FRIEND_DESIGN_IMAGES[design.id]}
  accessibilityLabel={design.name}
  resizeMode="contain"
  style={{ width: 96, height: 96 }}
/>
```

import 경로는 저장소 루트 컴포넌트 기준입니다. 실제 뽑기는 백엔드가 추첨·포인트 차감·중복 요청 처리·소유권 저장을 한 번의 처리로 확정하고, 앱은 서버가 반환한 디자인 ID로 이미지를 표시하도록 연결합니다. 이 변경에는 실제 포인트·소유권·네트워크 API를 추가하지 않습니다.

### 가중치 변경

```ts
const eventPool = createBibleFriendDrawPool({
  styleWeights: { unique: 20 }, // 모든 유니크의 가중치 변경
  designWeights: { 'love-otter:unique': 0 }, // 특정 디자인만 제외
});
```

개별 디자인 설정이 계열 설정보다 우선합니다. 0은 추첨에서 제외하며, 음수·소수·NaN·무한대·알 수 없는 ID와 빈 풀은 거부합니다.
표시 확률은 `weight / pool.totalWeight`로 계산합니다. 천장·중복 보상·뽑기 비용·이벤트 기간은 아직 설정하지 않았습니다.

## 에셋 규격과 모션

- 신규 117장: **288×288 투명 PNG**, 피벗 기준 (144,264), 가장 긴 외형 240px 이내, 최대 128색 팔레트. 기존 기본형 파일은 보존했습니다.
- 생성된 3×3 시트에서 연결된 동물·소품을 묶어 분리했으며, 격자선을 기준으로 잘라 모자나 발이 잘리는 것을 방지했습니다.
- 원본 시트의 순서는 햇살 소풍 / 학자 / 정원사 / 선원 / 탐험가 / 등불 축제 / 별빛 / 로열 / 전용 유니크입니다.
- **전체 130종이 5종 모션을 지원합니다.** 모든 디자인에 `animationReady: true`를 표시했습니다. 기본형은 기존 208장, 의상 117종은 전용 아틀라스 117장을 사용합니다.
- 모션 재생은 `BibleFriendDesignSprite`를 사용합니다. 규격·슬롯·재생 예시는 [전체 디자인 모션](../design-motions/README.md)을 참고하세요.
- `manifest.json`은 파일·크기·등급·기본 가중치·모션 준비 여부를, `art-direction.json`은 유니크 제작 방향을 기록합니다.
- 생성형 이미지 특성상 작은 소품·색감에 차이가 있고 엄밀한 48/64px 수작업 격자 스프라이트는 아닙니다. 64~96dp 실기기 가독성 확인이 필요합니다.

## 개발 확인

저장소 루트에서 `python3 -m http.server 8080`을 실행한 뒤 아래 경로를 엽니다.

`http://localhost:8080/assets/characters/bible-friends/designs/preview.html`

캐릭터·등급으로 필터링하고 전체 130종 풀에서 무료 체험 추첨을 해볼 수 있습니다. 개발 확인용 페이지이며 앱 화면은 아닙니다.
